# 📊 Product Sentiment Analyzer and Review Dashboard

## 📌 Project Description
The **Product Sentiment Analyzer and Review Dashboard** is a web-based application that collects product reviews from e-commerce websites using dynamic web scraping. The system analyzes the reviews using Natural Language Processing (NLP) techniques and displays insights through an interactive dashboard.

Users can explore sentiment trends, review distributions, and key insights through visual charts.

## 🛠️ Technologies Used

- Python
- Web Scraping (Selenium)
- NLP (TextBlob)
- Data Analysis (Pandas)
- Data Visualization (Matplotlib, Seaborn)
- Interactive Dashboard (Streamlit)

## ⚙️ Project Workflow

1️⃣ Web Scraping product reviews  
2️⃣ Data preprocessing and cleaning  
3️⃣ Sentiment analysis using NLP  
4️⃣ Data visualization using charts  
5️⃣ Interactive dashboard deployment
